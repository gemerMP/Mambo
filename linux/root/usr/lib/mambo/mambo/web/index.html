ПРОЗРАЧНЫЙ СТАТУС

Что сейчас работает

Для XHTTP и режима SOCKS5. Скачать официальное ядро Xray с GitHub один раз, без прав администратора.

Подключение на ПК

В режиме «VPN всей системы» приложение запрашивает права через Polkit и создаёт TUN. В режиме «Только SOCKS5» укажи 127.0.0.1:10808 в браузере или другом приложении. Для DNS через прокси используй SOCKS5 с удалённым разрешением имён (socks5h).

Для VPN на Arch установи новый пакет Mambo через pacman — он подтянет sing-box и Polkit. Android и переключение серверов при обрыве пока не реализованы.

Режим Lite

mambo-lite connect ID_СЕРВЕРА

Тот же список серверов и маршруты. Без интерфейса и загрузки артов. Ctrl+C завершает подключение.
