# Mambo 0.9.3

Нативный VPN-клиент для Linux x64, Windows x64 и Android 10+.

## Изменения

- На главной больше нет заголовка «Связь без суеты».
- Выбор сервера с главной: «Серверы» → нажатие на сервер → возврат на главную.
- Пинг выбранного или всех серверов прямо в списке, с результатом рядом с сервером.
- GET/HEAD, TCP/ICMP, Default/Double/KeepAlive сохранены.
- Новая диагностика: доступ напрямую и через прокси, возможная фильтрация, DNS по UDP, стабильность пяти HTTPS-запросов, проверка WireGuard.
- Счётчики загрузки/выгрузки и скорости через VPN, за сеанс. Включают проверки соединения; прямой трафик не учитывается. Это байты полезной нагрузки ядра, а не данные для сверки с оператором.
- Журнал показывает этапы соединения, обезличенные ошибки ядра, результаты тестов и трафик при отключении. Ссылки и ключи скрываются.
- В Windows перенесён интерфейс Linux 0.9.2: семь тем, Noto Sans, таймер, минимализм без персонажа и цитат, мягкие карточки. Windows использует Qt Widgets.
- На Android добавлены те же палитры, заметный выбор темы, минимализм, Noto Sans, таймер; главная начинается с подключения.
- MTU применяется к внутреннему WireGuard-ядру, а не только к системному TUN. При проблемах с крупными пакетами можно выбрать 1280 в маршрутизации.
- Endpoint WireGuard разрешается до TUN, с предпочтением IPv4 при наличии маршрута. Активный туннель используется для проверки своего профиля; второй с тем же ключом не запускается.
- В Windows проверка локального порта распознаёт активного слушателя и не принимает закрытые соединения TIME_WAIT за работающий VPN. В Linux сохранено исправление 0.9.2.

## Установка

### Windows 10/11 x64

Распакуйте весь `Mambo-Windows-x64-0.9.3-Qt.zip` в отдельную папку. Запустите `Mambo.exe` и подтвердите запрос администратора. Папки `runtime`, `app`, `bin` должны находиться рядом с EXE. Python, Qt, Xray, sing-box и Wintun включены. WebView2 для Mambo.exe не нужен.

Перед обновлением закройте старую версию и отключите VPN. Профили находятся вне каталога программы; новая сборка использует тот же каталог профилей.

### Arch / EndeavourOS

```bash
sudo pacman -U ./mambo-0.9.3-1-x86_64.pkg.tar.zst
mambo
```

### Debian / Ubuntu

```bash
sudo apt install ./mambo_0.9.3-1_amd64.deb
mambo
```

### Остальные Linux x64

Распакуйте `Mambo-Linux-x64-0.9.3.tar.gz`, установите зависимости из `START-HERE.txt` и запустите из распакованного каталога:

```bash
sudo python3 install.py
mambo
```

В Linux само окно запускается от обычного пользователя. Polkit запрашивает пароль при настройке системного VPN. Обновления Linux можно устанавливать поверх 0.9.2 без удаления профилей.

### Android

В этом выпуске APK имеют отдельный идентификатор `app.mambo.next.preview` и имя **Mambo Next Preview**. Прежний ключ подписи приложения `app.mambo.next` не входил во вложения. Поэтому это отдельная установка рядом с текущим Mambo Next, а не обновление поверх него. Старую версию удалять не требуется. Профили нужно импортировать в Preview заново.

- ARM64: `Mambo-Next-0.9.3-arm64-preview.apk` для большинства телефонов.
- Universal: `Mambo-Next-0.9.3-universal-preview.apk` для других архитектур.

Откройте APK через «Файлы → Загрузки», разрешите установку из этого источника, установите Mambo Next Preview. Для подключения подтвердите системное разрешение VPN. Android позволяет держать активным только один VPN.

Новый ключ Preview выдаётся отдельным приватным архивом. Его нельзя публиковать. Он позволяет выпускать следующие обновления Preview и не заменяет прежний ключ основного Mambo Next.

## Диагностика WireGuard

Сначала выберите WireGuard в «Серверах», затем откройте «Пинг → Диагностика сети → WireGuard». Если ответа нет, проверьте Endpoint и UDP, PSK, Reserved и AllowedIPs. Параметр MTU 1280 теперь применяется к самому WireGuard. После изменения маршрутизации переподключите VPN.

В журнал не вставляйте приватные ключи. Для разбора конкретного сервера достаточно журнала после неудачного подключения и описания формата профиля. Прохождение обычного VPN не доказывает доступность WireGuard/UDP.

Тест сравнения доступности относится только к проверенным адресам. Он не устанавливает наличие или отсутствие DPI. При TUN на настольных ОС прямой путь проверяется через отдельный выход sing-box вне TUN; на Android приложение исключено из VPN. Прокси-проверки учитывают правила маршрутизации.

## Исходники и сборка

- `linux/root/usr/lib/mambo/mambo` — общий исходный код настольного клиента.
- `linux` — полное дерево Linux с предоставленными Qt, Xray и sing-box.
- `windows` — Windows-комплект с тем же Python-кодом, предоставленными средой Python, Qt, ядрами и лаунчерами.
- `android/src` — Java-код Android; `android/upstream` — исходники используемых нативных компонентов.
- `tests`, `protocol-tests`, `android/tests` — проверки.
- `verification` — результаты проверок текущего выпуска.

Сборка настольных пакетов из корня проекта:

```bash
python3 tools/build_linux.py --bundle linux --output dist
python3 tools/build_windows.py --output dist
python3 tools/verify_linux_packages.py --bundle linux --output dist
```

Android использует Java 17, Python 3 и закреплённые SHA-256 зависимости из `android/build.py`. Для Preview восстановите его ключ и пароль в `android/.build/private/` и выполните:

```bash
MAMBO_APP_ID=app.mambo.next.preview python3 android/build.py
```

Для основного `app.mambo.next` нужен его прежний ключ подписи; автоматически создавать новый ключ для обновления основного приложения сборщик не будет. Сгенерированный каталог `.build/private` и приватные архивы подписи исключены из исходников.

На этой среде Java требует `LD_LIBRARY_PATH=/usr/lib/jvm/java-17-openjdk-amd64/lib:/usr/lib/jvm/java-17-openjdk-amd64/lib/server`. Обычно на установленном JDK это не требуется.

См. `TEST_REPORT.md` для точных границ проверки. На физическом Android и Windows этот выпуск здесь не запускался; системный TUN недоступен в среде сборки.
