Mambo 0.9.3 — Linux x86_64

Исправлена ошибка повторного подключения после отключения:
закрытое TCP-соединение больше не считается занятым портом.
Внутренние соединения Mambo явно исключены из маршрута TUN.
После запуска автоматически проверяются HTTPS через VPN и системный маршрут.
Статус «Подключено» появляется после успешной проверки доступа.
Темы, минимализм, шрифт Noto Sans и таймер из 0.9.1 сохранены.

Обновление с 0.9.0/0.9.1: сначала отключи VPN, закрой Mambo
и установи новый пакет поверх старого.
Не удаляй ~/.config/mambo — там находятся твои профили и настройки.

Arch / EndeavourOS:
  sudo pacman -U ./mambo-0.9.3-1-x86_64.pkg.tar.zst

Debian / Ubuntu:
  sudo apt install ./mambo_0.9.3-1_amd64.deb

Другие Linux:
  Распакуй весь Mambo-Linux-x64-0.9.3.tar.gz, открой терминал внутри
  полученной папки и выполни: sudo python3 install.py

Для архива tar.gz предварительно нужны Python 3.10+, Polkit/pkexec с агентом
в графической сессии, ALSA utils или PulseAudio utils, fontconfig,
libxkbcommon-x11, OpenGL/EGL и библиотеки XCB, включая xcb-cursor, icccm,
image, keysyms, render-util, xinerama и xkb. Зависимости в пакетах Arch/DEB
перечислены в метаданных, пакетный менеджер установит их автоматически.
Qt и VPN-ядра входят в комплект. Для VPN требуется /dev/net/tun.

После установки открой Mambo через меню приложений или командой mambo.
Запускай окно обычным пользователем. При подключении VPN появится запрос
прав через Polkit. Консольная версия: mambo-lite.

Смена темы: поле «Тема» справа сверху либо раздел «Вид и звук».
При возврате из минималистичной темы восстанавливается выбор персонажа.
Таймер начинает отсчёт после запуска VPN/прокси-ядра, обнуляется при
отключении или завершении ядра. Смена темы не сбрасывает время.
Проверка доступа запускается автоматически. Её можно повторить кнопкой
«Проверить доступ». Если показано «Нет доступа», причина появляется ниже
и в разделе «Журнал». Запуск ядра сам по себе не подтверждает доступ.

Импорт профилей и их формат не менялись.
Существующие VLESS/Trojan/WireGuard-профили остаются на месте.
Системный TUN и подключение к твоему серверу в сборочной среде
проверить нельзя. Если после обновления интернета нет, сохрани журнал
после попытки подключения и пришли его. Приватный ключ присылать не нужно.
Подробности проверки: /usr/share/doc/mambo/TEST_REPORT.md.
